# 미니 뱅킹 시스템 (RSA 로그인 + 계좌 관리)

헤드소프트(주) SM개발-디지털뱅킹 직무 지원을 위한 2일 실습용 프로젝트입니다.
Java로 계좌 관리 기능을 구현하고, 로그인 과정에 실제 인터넷뱅킹과 동일한 방식의
RSA 공개키 암호화를 적용했습니다.

## 구성

- `src/RSAUtil.java` : RSA 키 생성, 암호화, 복호화 유틸리티
- `src/AuthService.java` : 공개키 배포 → 클라이언트 암호화 → 서버 복호화/검증 로그인 로직
- `src/Account.java` : 계좌 모델 (잔액, 거래내역)
- `src/Bank.java` : 계좌 개설/입금/출금/이체 핵심 로직
- `src/Main.java` : 콘솔 메뉴 (로그인 후 계좌 관리)
- `BUGLOG.md` : SM(유지보수) 실습용 이슈 대응 로그 템플릿 — **꼭 직접 채워보세요**

## 실행 방법 (로컬 PC, JDK 17 이상 필요)

```bash
cd src
javac *.java
java Main
```

실행 후 데모 계정(아이디: `demo`, 비밀번호: `1234`)으로 로그인하면,
콘솔에 RSA로 암호화된 비밀번호 값이 출력되는 것을 확인할 수 있습니다.
로그인 후에는 계좌 개설, 입금, 출금, 이체, 거래내역 조회 메뉴를 사용할 수 있습니다.
